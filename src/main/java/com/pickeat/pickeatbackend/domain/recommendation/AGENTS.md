# recommendation 도메인

이 폴더 코드를 고칠 때 지킬 규칙이다. 자세한 결정과 기록은 [docs/domains/recommendation.md](../../../../../../../../docs/domains/recommendation.md), 공통 규칙은 루트 [AGENTS.md](../../../../../../../../AGENTS.md).

- 2026-11-09 결정: 식당 DB 제거 + 실시간 검색 + 랜덤 추천으로 개편한다(구현 전). 새 작업은 이 방향과 충돌하지 않게 한다.
- 현재 코드: DB에서 반경 내 후보를 먼저 찾고, 부족한 카테고리만 Google로 보충(같은 구역·카테고리 6시간 쿨다운)한 뒤 점수 상위 10개를 세션에 저장, 5개 노출.
- 점수는 `RecommendationScoreCalculator`: 평점(리뷰 수 보정 prior 3.5·20건) 0.7 + 거리 0.3 + 동행 가산 0.1, 반경 1km 이하는 0.8/0.2.
- 반경은 `SearchRadius`: 수도권·부산 500/1000/2000m(기본 1000), 그 외 1000/3000/5000m(기본 5000). 후보가 적어도 반경을 자동으로 넓히지 않는다.
- 필터: 30분 뒤 영업 중, 카테고리, 가격 범위 겹침, 데이트면 프랜차이즈 제외(`curated/franchise-brands.txt`), 주차 조건.
- 추천 세션 식별자는 `Long`을 유지한다.
