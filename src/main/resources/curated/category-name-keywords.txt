# 식당 이름으로 음식 카테고리를 보정하는 키워드 (2026-10-08)
# Google이 준 유형이 실제와 다르거나(예: 샤브칼국수·장어집이 japanese_restaurant) 그냥 restaurant로만 오는
# 식당이 있어서, 이름에 아래 키워드가 들어 있으면 Google 유형보다 이 카테고리를 우선한다.
#
# 형식: "카테고리: 키워드, 키워드, ..." — 카테고리는 FoodCategory 이름.
#       "카테고리+보조카테고리: 키워드, ..." — 두 카테고리 요청 모두에 추천된다(응답의 foodCategory는 앞의 것).
# '#'으로 시작하는 줄과 빈 줄은 무시한다.
# 여러 키워드가 걸리면 가장 긴 키워드를 따른다(쌀국수 > 국수, 타코야끼 > 타코). 길이가 같으면 위에 적힌 것이 이긴다.
# "샤브", "죽", "오리", "회", "바"처럼 다른 단어에 섞여 들어가기 쉬운 말은 넣지 않는다.
