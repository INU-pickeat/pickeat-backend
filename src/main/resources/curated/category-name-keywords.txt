# 식당 이름으로 음식 카테고리를 보정하는 키워드 (2026-10-08)
# Google이 준 유형이 실제와 다른 경우가 있어서(예: 샤브칼국수·장어집이 japanese_restaurant),
# 이름에 아래 키워드가 들어 있으면 Google 유형보다 이 카테고리를 우선한다.
# 형식: "카테고리: 키워드, 키워드, ..." — 카테고리는 FoodCategory 이름. '#'으로 시작하는 줄과 빈 줄은 무시한다.
# 여러 키워드가 걸리면 가장 긴 키워드를 따른다. 판별 규칙은 FoodCategoryNameOverride 참고.
# 주의: 키워드를 바꿔도 이미 DB에 있는 식당은 Google에서 다시 받아올 때까지 그대로다. 기존 식당은 마이그레이션으로 고친다(V22 참고).
